# Ustaz API contract v1

Shared by `backend/` (implements) and `app/` (consumes). Change it only through a commit that updates both sides.
Spec: `docs/superpowers/specs/2026-10-19-ustaz-design.md`.

## Conventions

- Base URL: `{APP_URL}/api/v1`. JSON only. `Accept-Language: ar|en` selects messages (default `ar`).
- Auth: Sanctum bearer token. Every request after login sends `Authorization: Bearer <token>` and
  `X-Device-Id: <uuid>` (UUID v4 generated by the app on first run, kept in storage).
- Success: `{"data": ...}`; lists add `{"meta": {"current_page", "last_page", "per_page", "total"}}` (page size 20).
- Errors: `{"message": "<localized>", "code": "<machine_code>", "errors": {"field": ["..."]}?}`.

| HTTP | code | Meaning |
|---|---|---|
| 401 | `unauthenticated` | missing/expired token |
| 403 | `device_pending` | login from a non-bound device; a reset request now exists |
| 403 | `account_blocked` | teacher blocked the student |
| 403 | `locked` | content needs a subscription or a passed gating quiz |
| 404 | `not_found` | |
| 409 | `already_submitted` / `review_already_requested` / `exam_not_open` | |
| 422 | `validation_failed` / `code_invalid` / `code_expired` / `code_used_up` | |
| 429 | `too_many_requests` | throttle |

## Shapes

```
Student      { id, name, phone, parent_phone, level: Level, created_at }
Level        { id, name }
Category     { id, name, position, is_free, is_subscribed, ends_at|null,
               lectures_count, exams_count, papers_count }
LectureCard  { id, title, position, is_free, is_locked, progress_percent, thumbnail_url|null }
Lecture      { id, title, description|null, is_free, is_locked, category_id, segments: Segment[] }
Segment      { id, type: video|pdf|quiz, position, title, is_gating, is_locked, passed|null,
               video?: { youtube_id, duration_seconds, last_position_seconds },   // only when not locked
               pdf?:   { url },                                                   // signed, 30 min
               quiz?:  { assessment_id, pass_percent, best_percent|null } }
ExamCard     { id, title, opens_at, closes_at, duration_minutes, state: upcoming|open|closed,
               attempt: { id, status: in_progress|submitted, percent|null }|null, is_locked }
Paper        { id, title, url }                                                    // signed, 30 min
Announcement { id, title, body|null, image_url|null, created_at }
Question     { id, text|null, image_url|null, options: [{ id, text|null, image_url|null }] }
Attempt      { id, assessment_id, kind: quiz|homework|exam, started_at, deadline_at|null, server_time,
               status: in_progress|submitted, questions: Question[], answers: { question_id: option_id } }
Result       { attempt_id, score, max_score, percent, passed|null, submitted_at,
               review_available, review_request: { status: pending|accepted|rejected, reply|null }|null }
ReviewItem   { question: Question, chosen_option_id|null, correct_option_id, is_correct, explanation|null }
Notification { id, title, body, data, read_at|null, created_at }
```

`youtube_id` is returned only to the bound device of a student who can open the segment.

## Endpoints

### Auth & profile
| Method | Path | Body | Returns |
|---|---|---|---|
| GET | `/levels` | — | `Level[]` (public) |
| POST | `/auth/register` | `name, phone, parent_phone?, password, password_confirmation, level_id, device_id` | `{token, student}` |
| POST | `/auth/login` | `phone, password, device_id` | `{token, student}`, or 403 `device_pending` |
| POST | `/auth/logout` | — | 204 |
| GET | `/me` | — | `Student` |
| PUT | `/me` | `name?, parent_phone?` | `Student` |
| POST | `/me/fcm-token` | `token` | 204 |

Phone: Egyptian mobile `^01[0125][0-9]{8}$`, unique. Password min 8. Login throttle 5/min per phone+IP.
No password reset endpoint: the teacher resets it in the panel.

### Home & content
| Method | Path | Returns |
|---|---|---|
| GET | `/home` | `{announcements: Announcement[], continue_watching: LectureCard[] (≤5), categories: Category[], free: LectureCard[] (≤10)}` |
| GET | `/categories` | `Category[]` of the student's level, ordered by position |
| GET | `/categories/{id}` | `{category: Category, lectures: LectureCard[], exams: ExamCard[], papers: Paper[]}` (papers empty when locked) |
| GET | `/lectures/{id}` | `Lecture` |
| POST | `/lectures/{id}/progress` | body `{segment_id, position_seconds, watched_seconds}`; 204. Sent every 15 s and on pause/exit. |
| GET | `/announcements` | paginated `Announcement[]` |

### Access
| Method | Path | Body | Returns |
|---|---|---|---|
| POST | `/codes/redeem` | `code` | `{category: Category}` (now subscribed); 422 `code_*` |
| GET | `/subscriptions` | — | `[{category: Category, starts_at, ends_at|null}]` |

### Assessments (quiz segments, homework, exams — one engine)
| Method | Path | Body | Returns |
|---|---|---|---|
| POST | `/assessments/{id}/attempts` | — | `Attempt` (resumes the open one if any; exams: 409 `exam_not_open` outside the window, 409 `already_submitted` when attempts are used up) |
| PUT | `/attempts/{id}/answers` | `{question_id, option_id}` | 204 (autosave each answer) |
| POST | `/attempts/{id}/submit` | — | `Result`; server auto-submits at `deadline_at` |
| GET | `/attempts/{id}/result` | — | `Result` |
| GET | `/attempts/{id}/review` | — | `ReviewItem[]`, 403 `locked` until review is available |
| POST | `/attempts/{id}/review-request` | `note` (max 500) | `Result`; once per exam attempt → 409 `review_already_requested` |
| GET | `/me/results` | — | paginated `Result & {title, kind}` |
| GET | `/me/homework` | — | `[{assessment_id, title, lecture_id, attempt: {status, percent}|null}]` |

### Notifications
| Method | Path | Returns |
|---|---|---|
| GET | `/notifications` | paginated `Notification[]` |
| POST | `/notifications/{id}/read` | 204 |

## Caching contract (backend)
- Cached per level (tag `level:{id}`): `/categories`, category content lists, lecture structure (without the
  per-student fields). Per-student fields (`is_subscribed`, `is_locked`, progress, attempts) are merged from a
  per-student cache (tag `student:{id}`, TTL 10 min, flushed on subscription/progress/attempt writes).
- Teacher edits flush the level tag through model observers.
